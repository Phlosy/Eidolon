## 真实运行

七次尝试均使用隔离数据库和目录、固定镜像、显式真实调用开关；planning/review fixture
关闭。每次费用上限为 **0.05 美元**，每个请求输出最多 768 token，选定模型探测计入预算。
前六次最多 5 个上游请求、4 轮业务往返；最后一次最多 7 个请求、6 轮业务往返，
费用上限保持不变。中继按每次请求的保守预留控制剩余额度，完成后按实际返回用量结算。

首次 OpenClaw 暴露出旧 Artifact 表与当前项目 Drive 文档 ID 的冲突。9 个真实数据库反例
确认并修复了引用校验：2 个合法引用不再被拒绝，7 类无效引用不再被旧表同编号记录误放行。
成功的 OpenClaw 复验没有显式提交 artifact_refs，不能把它作为引用修复的直接证明。
首次最终回执轮的具体失败原因没有采集到，仍未核实。

Hermes 后续暴露出工具目录未公开已有 ArtifactType 枚举。新增反例先证明未知值会进入
失败意图，再补齐 schema，使其在保存意图和审计之前被拒绝；合法 readme 经真实工具桥
落库。嵌套 decision 和 operation_key 的帮助文字同步澄清，解析限制没有放宽。

最终验收要求：成功读取必须早于原始决定请求，且仅一个 Decision 和一个写审计生效；
管理场景只创建一个 Task。失败意图可以保留。最后补强的先读后写断言分别比较审计 ID
和原始 operation ID，防止决定重放冒充正确顺序。该断言已由独立只读复核确认，并对
两份成功真实回执核验；断言补强之后没有再次付费运行。
