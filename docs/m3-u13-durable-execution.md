# U13 持久执行引用与结构化遥测

日期：2026-09-20。实现基线：`5058da956044557b348911dc657ecf5c196e4153`。对应 [M3 计划 U13](m3-implementation-plan.md#u13-m34-durable-execution-and-telemetry) / R4。U13 已完成本地整合验证，M3.4 仍待 U14–U17。

## 执行事实

`WorkSession` 继续表示逻辑会话，原 `runtime_session_ref` 保持本地会话身份。新增 `RuntimeAttempt` 记录每个请求的尝试次序、幂等键、输入摘要、原实例指纹、远端 run / session 引用、进展时间及终态出处。普通 Worker 和受控 Manager / Reviewer 都通过同一个 [写入服务](../apps/server/app/work/telemetry.py) 记录。

宿主先提交请求身份，再发起外部执行；adapter 收到 run ID 后提交接受事实，随后才等待远端结果。请求摘要覆盖提示词、声明的执行上下文和稳定身份，不保存其原文，也不宣称等价于完整 HTTP / RPC 字节。相同请求键不能改用不同的输入。

正常管理对话的每一轮是不同请求，尝试次数均从 1 开始。只有同一请求的显式技术重试才增加 `technical_retry_count`。旧会话没有采集过的重试历史保持 `NULL`；仅正式创建的新会话初始化为 0，不改变任务的返工计数。

## 不确定结果与历史保护

本地超时、断流、传输错误和调用方取消记录在独立的 `host_outcome / host_reason / host_observed_at` 中。远端结果不明时，尝试保持 `unknown`，不填写已确认的结束时间和终态出处；以后取得明确远端证据后仍可收敛。已确认的远端结果、接受引用和请求身份不可重写，尝试记录不可删除。

重新查询从保存的尝试重建原运行引用，核对公司、Person / Employee 归属、原实例与连接指纹，再从当前 SecretStore 取凭证。替换实例或转移归属后拒绝查询，不能用新实例解释旧执行。查询本身不发起执行，也不直接推进 Task、Review 或 Decision。

## 遥测保留与边界

`RuntimeTelemetry` 只保存冻结词表中的结构化观察。token 片段、隐藏推理、完整提示词、工具参数和错误原文不进入该表；未知事件、非法时间和未识别用量保留通用原因，不补造成功或零用量。

事件按尝试去重，按记录 ID 分页，每页最多 100 条；观察保留 7 天，过期记录从读面过滤，并通过有上限的批次删除。乱序和晚到消息不覆盖确认终态，也不直接调用领域写入。遥测过期不删除持久尝试身份。

## 迁移

新增 v56（`56b215ea43f0`），接在 v55（`55a104d932ef`）之后。迁移只增加事实表和可空重试计数，保留原 WorkSession 快照、身份、用途和目标守卫。SQLite 的元数据建库与迁移建库使用同等约束。

空尝试库支持 up / down / up；已有尝试时，降级在 DDL 前明确拒绝，以免删除执行历史。开发数据库未迁移。本项目已有迁移链仅声明支持 SQLite。
