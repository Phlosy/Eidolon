# Eidolon 游戏化界面改版（分支 `design/game-ui`）

> 本分支只做界面与体验，不改业务逻辑。所有改动在独立目录 `~/workspace/Eidolon-Game` 中进行，
> 远程仍指向 `git@github.com:Phlosy/Eidolon.git`。

## 0. 定位：这是游戏，不是后台工具

用户是「老板」，Eidolon 是「一家会自己运转的 AI 公司」。
判断一个界面好不好，不看信息密度，而看三件事：

1. **有没有重心**——一屏只允许一个主角，其余都是配角。
2. **有没有节奏**——进入、推进、完成都有明确反馈。
3. **有没有沉浸感**——像在经营一家公司，而不是在填表。

## 1. 三条不可让步的原则

| # | 原则 | 反例（现状） |
|---|---|---|
| 1 | **一屏一个重心**：中央舞台 + 环绕 HUD | 每个面板都有标题、徽章、按钮，互相抢注意力 |
| 2 | **图标优先、文字兜底**：高频动作一律图标按钮 + tooltip | 侧栏、卡片、工具栏大量文字按钮 |
| 3 | **信息按需展开**：默认只显示「我现在能做什么」 | 首屏同时铺开员工、项目、运行时、资产、告警 |

## 2. 视觉层级（由内到外）

```
        ┌──────────────────────────────┐
        │            HUD               │  轻量状态条：在线员工 / 进行中项目 / 下一步
        │  ┌────────────────────────┐  │
        │  │                        │  │
        │  │        Scene 舞台      │  │  中央：公司全景 / 办公室 / 项目现场
        │  │   （最大面积、环境光） │  │
        │  │                        │  │
        │  └────────────────────────┘  │
        │        Panel 抽屉（按需）     │  明细、列表、日志
        └──────────────────────────────┘
                    Modal 决策             招聘 / 立项 / 评审：全屏聚焦，一次只问一件事
```

- **Scene**：承担沉浸感，允许环境光、网格、粒子、微动效。
- **HUD**：半透明、轻，只显示 3 个以内的关键指标和一个「下一步」。
- **Panel**：从边缘滑出，不常驻；打开时才占空间。
- **Modal**：关键决策，全屏压暗，主行动唯一。

## 3. 排版系统（Word 式层级）

全站文字只允许两种写法：`.type-*` 类，或 `<Text variant="...">` 组件。
**禁止**页面里再写 `text-xs` / `text-[11px]` 这类一次性字号。

| 层级 | 用途 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|---|
| `display` | 封面、空状态大标题 | clamp(2.5–4.5rem) | 700 | 1.02 | -0.045em |
| `h1` | 页面标题 | clamp(1.75–2.5rem) | 650 | 1.12 | -0.035em |
| `h2` | 区块标题 | 1.5rem | 650 | 1.2 | -0.02em |
| `h3` | 卡片标题 | 1.125rem | 600 | 1.3 | -0.01em |
| `h4` | 小标题 | 0.9375rem | 600 | 1.35 | — |
| `body` | 正文 | 0.9375rem | 400 | 1.7 | — |
| `bodySm` | 次要正文 | 0.8125rem | 400 | 1.65 | — |
| `caption` | 辅助说明 | 0.75rem | 400 | 1.55 | — |
| `overline` | 分组标签 / eyebrow | 0.6875rem | 600（mono） | 1.3 | 0.14em |
| `table` | 表格 | 0.8125rem | 400（tabular） | 1.45 | — |
| `tutorial` | 教程 / 旁白 | 0.875rem | 400 | 1.75 | — |
| `code` | 代码 / 路径 | 0.8125rem（mono） | 400 | 1.6 | — |
| `telemetry` | 指标数字 | 0.8125rem（mono） | — | 1.2 | -0.025em |

**字体选择（大众、跨平台、可读性优先）**

- 拉丁 / 数字：**Inter Variable**——现代 UI 事实标准，屏幕小字号清晰。
- 中日韩：**Noto Sans SC Variable**——开源、字面均衡、跨平台；macOS 回退 PingFang SC，Windows 回退 Microsoft YaHei。
- 等宽 / 遥测：**JetBrains Mono Variable**——数字等宽，适合指标与代码。

**中英混排细节**

- 中文语境开启 `palt`（标点比例宽度），中英混排更整齐。
- 中文正文行高 1.7（比纯英文高），标题 `text-wrap: balance`，正文 `text-wrap: pretty`，减少孤字。
- `<html lang>` 随语言切换自动更新；数据里混入的另一种语言用 `<Lang>` 包一层。

## 4. 组件化落地规则

1. 文字 → `<Text variant>` / `H1..H4` / `Body` / `TableText` / `TutorialText` / `Telemetry`。
2. 颜色 → 只用语义 token（`text-muted-foreground`、`text-primary`、`text-success`…），禁止 hex。
3. 主行动 → 每屏唯一实心按钮；其余一律图标按钮（带 `aria-label` + tooltip）。
4. 列表 > 8 条 → 分页或虚拟滚动；详情 > 2 屏 → 分 Tab 或抽屉。
5. 动效 → 只用于「状态变化」和「引导」，全部尊重 `prefers-reduced-motion`。
